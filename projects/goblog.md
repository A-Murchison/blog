This blog was created with goblog.

A minimal static site generator that turns Markdown files into a static website hosted on GitHub Pages.

## Features

- Markdown + YAML frontmatter
- Multiple content types (posts, projects)
- Tag pages
- Sitemap generation
- GitHub Actions deploy
